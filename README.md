# ERP / MES 制造业务演示

在线演示：[打开 ERP / MES](https://youth886.github.io/erp-mes-demo/)

源码：[下载可读前端源码](frontend-source.zip)

使用已有的虚构业务数据，覆盖产品、客户、销售订单、库存、仓库入库、BOM、工艺路线、生产订单、MES、库存流水、业务流程和概览共12个页面。

## 在线运行方式

本版本为纯前端构建，不依赖 Python、PostgreSQL 或本机8000接口。
初始数据来自项目现有演示记录，没有重新随机生成数据。
新建、修改、确认、报工、入库在浏览器中处理，结果保存在当前浏览器的网站存储中。其他访客不受影响，不是多用户共享系统。
右上角“重置演示”可以恢复初始数据。清除网站存储或换浏览器也会恢复初始状态。

## 上传 GitHub Pages

上传本文件所在目录的内容，根目录必须有 index.html 和 assets/。
仓库 Settings → Pages → Deploy from a branch → main → /(root) → Save。
网页使用 # 路由及相对资源路径，适用于仓库子路径，刷新子页面也能打开。
不需要上传原项目的 backend、.venv、node_modules、数据库连接配置或输出日志。

## 源代码

frontend-source.zip 为前端可读源码和依赖锁文件，解压后得到 source/ 目录。
修改时进入 source/，运行 npm ci，然后 npm run dev:demo。
构建运行 npm run build:demo，将生成的 dist-demo/ 内容更新到网站根目录。
源码中的 npm run dev 为原来的接口模式，需要自行启动本地后端；公开演示请使用带 demo 的命令。

## 演示流程

销售订单：新建订单 → 确认并选分配仓库 → 按缺口生成生产订单。
生产订单：检查物料需求 → 下达生产（产品需已配置有效工艺路线）。
MES：选择关联生产单 → 按顺序报工。
生产订单：工序完成后生产入库 → 库存增加并自动补足来源订单预留。
业务流程：查看阶段状态；库存流水：查询和导出来源记录。

浏览器业务处理为演示实现，覆盖页面主要操作，不代表经过生产系统完整验收。没有销售发货、财务收款、真实身份权限或跨设备数据同步。
